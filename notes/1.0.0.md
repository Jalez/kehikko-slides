- **Slides for your paper, written in Markdown.** Each deck is a plain Markdown file in the project, with speaker notes under each slide, that you or an agent can write and edit.
- **Slides that follow the paper.** Link a slide to a section of the paper, and the deck turns to it as you read; showing the slide turns the paper.
- **Present from the canvas.** Start a talk from the container's menu and step through it with the keyboard, full screen.
- **Pictures from your project.** A slide can show an image from the project by its path.
- **Every change can be undone.** Each edit, yours or an agent's, is kept in the deck's history.
