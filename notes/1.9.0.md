Kind: feature

- **Slides find the document they are about.** Slides now ask Kehikot which module keeps the project's document, and cite and show figures from wherever that module keeps it, instead of assuming one place.
- **Clear when there is no document.** With nothing keeping a document in the project, a slide still cites and shows the project's own files; files in hidden folders are refused, as before.

## For agents

- `create_deck`, `link_slide` and `cite_slide` describe the operation, not another module's tools: read the document's sections and source with the tools the document provider offers. When a path or quote is refused, the error names the provider and its tool as it declares them.
- A citation or picture path under a dot-folder is read only inside the folder the document provider declares; with no provider, none is.
