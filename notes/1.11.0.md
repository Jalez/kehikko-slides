Kind: feature

- **Its folder says whose it is.** Slides now tells Kehikot that the slides folder in a project is its own and holds the decks with their speaker notes, citations and history, so a module that shows the project's files can say what a file there is and who writes it.

## For agents

- Slides now provides the `module.folders` service: `{ name: 'Slides', folders: [{ folder: 'slides', says: …, derived: false }] }`. Read it with `services.find('module.folders')` and `foldersOwned`.
